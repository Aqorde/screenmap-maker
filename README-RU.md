# aqorde ScreenMap Maker

Редактор направляющих для постановки кадра и подготовки референсов для генерации изображений и видео.

[Скачать для Windows](https://github.com/Aqorde/screenmap-maker/releases) · [English](README.md) · [Лицензия MIT](LICENSE.txt)

Выбери формат кадра, включи нужные слои и настрой центр перспективы. Перетащи точку за левую или правую кромку либо воспользуйся ползунком **«Перспектива X»**. Кнопка **«Сброс перспективы»** возвращает точку в центр кадра.

Сними **«Ограничить глубину»** при включённом PGFA, чтобы развернуть сетку в две плоскости. Диагонали образуют равномерный шаг на каждой горизонтали по всей ширине кадра. У глубины D0–D7 сплошные участки в центре и точечные продолжения по краям.

Направляющие можно наложить на фото и экспортировать в PNG или SVG. При экспорте можно приложить одноимённый шаблон промпта на русском или английском. Справка с примерами встроена в приложение.

В Releases есть установщик и portable ZIP. Для запуска portable-версии распакуй весь архив и открой `ScreenmapMaker.exe`.
